Speed S3 · PLC & HMI

Automatic car wash machine control, rewritten from scratch

The problem

The Speed S3 automatic car wash machine ran an old ladder program with fixed parameters, no fault codes and no way to see what the machine was doing.

What I built

A new ladder program for the Delta DVP-EC3 PLC in WPLSoft, with operator-adjustable wash parameters and versioned releases (program check registers confirm the version on site). HMI screens for Delta DOP-107DV and Weintek MT8071iE showing live motion and machine status, with settings operators can change. Weintek EasyAccess 2.0 for secure remote HMI access, and the full wiring and electrical diagram prepared for SASO certification.

The outcome

The machine is in service with a program the company owns and understands, adjustable on site and reachable remotely, with the paperwork ready for certification.
