Sparkles By Amal

Luxury jewellery e-commerce where every section is managed from the admin

The problem

A jewellery brand wanted a storefront that feels like a boutique, and a back office they could run without a developer.

What I built

A bespoke storefront (animated hero, AJAX filters, variants, 360° and video, reviews and Q&A, wishlist, compare, cart drawer) and a checkout with zone shipping, COD, bank transfer, Stripe, PayPal, JazzCash and EasyPaisa, wallet, reward points and gift cards. The admin has 12 roles and 50+ permissions, a homepage builder, a marketing suite (flash sales, bundles, spin wheel), WhatsApp automation for orders, OTP and abandoned carts, full SEO tooling and a REST API for mobile apps.

The outcome

The owners change products, campaigns, payments, couriers and messages themselves, without touching code.

Laravel 12 · MySQL · Bootstrap 5 · GSAP · Stripe / PayPal · JazzCash / EasyPaisa · Green API · Sanctum API
