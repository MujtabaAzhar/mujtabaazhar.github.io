Education Management Platform

Multi-tenant school management + LMS with seven roles

The problem

Schools juggle separate tools for admissions, fees, classes, staff and learning, and none of them talk to each other.

What I built

An architecture for a seven-role platform (Super Admin, Org Admin, Teacher, Student, Parent, Finance, HR) with per-tenant branding, subdomains and data isolation. JWT with refresh tokens and RBAC, real-time updates over Socket.IO, local and card payments, and CI/CD with Docker and GitHub Actions. Documented in PlantUML and an SRS before a line of code, with a six-phase roadmap.

The outcome

A fully specified platform with its foundations in place and a roadmap each school can be onboarded against.

React · TypeScript · Node/Express · MongoDB · Redis · Socket.IO · Stripe · JazzCash / Easypaisa · Docker · Nginx · GitHub Actions
