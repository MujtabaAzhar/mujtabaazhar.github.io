Machine Control Panel

Web dashboard for the wash machine: I/O, self-test, diagnostics and statistics

The problem

Engineers needed a clear screen to read inputs and outputs, test each actuator and review what the machine had been doing.

What I built

A multi-page control panel: a live dashboard, an I/O status map of every input and output, guided self-test, diagnostics, an event log, wash statistics and operating instructions, styled in the Speed Track brand.

The outcome

Commissioning and fault-finding moved from reading PLC registers to looking at a page.

HTML · CSS · JavaScript · Live I/O · Diagnostics · Event log
