AgentDesk

Multi-agent customer support assistant

The problem

One big prompt can't route, look things up, act and escalate reliably.

What I built

A support assistant where specialised agents (routing, knowledge retrieval, actions, escalation) are coordinated as a LangGraph state machine, with Qdrant for knowledge, PostgreSQL for conversations and gRPC between services.

The outcome

Each step is a small, testable agent instead of one opaque prompt.

FastAPI · LangGraph · gRPC · Qdrant · PostgreSQL
