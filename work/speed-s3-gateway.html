Speed S3 · Cloud Gateway

An ESP32-S3 that reads the PLC over RS-485 and reports every machine to the cloud

The problem

Installed machines were black boxes. When one stopped at a customer site, the only way to find out why was to send a technician.

What I built

Firmware for a Waveshare ESP32-S3 relay board wired to the PLC's COM2 port over RS-485 Modbus. It polls machine state, counters and sensor transitions, derives faults in software, stores every event in flash when offline and uploads when WiFi returns. A Laravel portal (installedmachine.speedtrackauto.com) lists every machine with live status, alarms, counters and an event log, and lets logged-in users send commands. Setup is a hotspot page: join S3-Setup-<serial>, enter WiFi, serial and API key.

The outcome

The company sees each installed machine remotely, diagnoses faults before driving out, and loses no data when a site's internet drops. Safety stays hard-wired: the E-stop never depends on the gateway.

ESP32-S3 · C++ / Arduino · Modbus RTU · RS-485 · Offline flash buffer · Laravel 12 · MySQL
