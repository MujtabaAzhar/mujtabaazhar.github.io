WhatsApp AI Support Bot

Answers customers on WhatsApp, only from the business manual

The problem

The car wash's WhatsApp number got the same questions all day (prices, hours, branches) and replies depended on whoever was free.

What I built

An auto-reply bot on Green API and Laravel. Each incoming message is verified, de-duplicated, stored and acknowledged immediately, then answered by an LLM grounded only in the business manual. When it can't help, it hands the chat to a human. Built to run on Hostinger shared hosting: no VPS, no Node, no Redis, no queue worker, with a one-time /setup page instead of SSH.

The outcome

Customers get instant, accurate replies at any hour, and staff only step in for the conversations that need a person.

Laravel · Green API · LLM API · Webhooks · Shared hosting
