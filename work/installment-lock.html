Machine Installment Lock

Sell a machine on instalments: it runs until a date, then asks for a code

The problem

The company wanted to sell machines on monthly instalments, with a fair way to pause a machine when a payment is missed.

What I built

The PLC keeps a lock date and stops the machine with a 'please contact the company' screen when it passes. After payment the portal issues a one-time code derived from the machine's API key, entered on the app or pushed over the internet. For machines without WiFi, the phone app relays: the gateway signs its upload, the phone carries it to the server over mobile data, and brings back a signed reply with the new code, settings and time.

The outcome

A new sales model for the business. The lock is off until the first code, so machines without a plan run normally, and every code and date is verifiable end to end.

PLC v3.12 · ESP32-S3 1.3.1 · Signed unlock codes · Laravel · Flutter app relay
