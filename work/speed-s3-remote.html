Speed S3 Remote

Android app that monitors and operates the wash machine over Bluetooth

The problem

Technicians needed to see and drive the machine from beside it, without a laptop, a cable or an internet connection.

What I built

A Flutter app that finds the gateway over Bluetooth LE, logs in with a PIN and shows live machine state, counters and alarms. Operators can run commands and jog motors, with jog stopping the instant a finger lifts or Bluetooth drops. Settings sit behind a separate 8-digit code, and remote web control can be switched off per machine from the app.

The outcome

The machine can be checked and operated from a phone on site. Remote commands are only accepted while a logged-in phone is connected, so the floor stays safe.

Flutter · Bluetooth LE · ESP32-S3 · PIN + settings code · Signed payloads
